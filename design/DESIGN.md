# RiseUp — редизайн фронтенда

Цель: заменить текущий вид `src/main/resources/static/` на новый дизайн «C». Бэкенд, API и бизнес-логика не меняются.

## Как читать макеты

В `design/screens/` лежат исходники макетов, по одному файлу на экран. Это **образец**, а не готовый код:

- вся разметка и стили написаны инлайн — переносить их надо в общий `styles.css` с классами и CSS-переменными;
- теги `<x-dc>`, `<helmet>`, `<sc-for>`, `<sc-if>`, `{{...}}`, `<script type="text/x-dc">` и `support.js` — служебный формат редактора макетов. В проект их не переносить. `<sc-for>` = цикл рендера в JS, `<sc-if>` = условный показ, `{{x}}` = подстановка данных;
- данные в блоке `renderVals()` — демо-данные. На сайте всё берётся из существующего API.

## Глобальные решения

- **Только тёмная тема.** Удалить переключатель темы, JS, который ставит `data-theme`, и все правила `html[data-theme="dark"] …` в `styles.css` и `<style>` страниц. Тёмные значения становятся базовыми.
- **Шрифты:** Unbounded 500/700/900 — заголовки и крупные числа, заголовки в верхнем регистре. Manrope 400–800 — весь остальной текст. Подключать через Google Fonts, Manrope + Plus Jakarta Sans убрать.
- **Контейнер:** `max-width: 1200px; margin: 0 auto; padding: 0 24px`.
- **Без эмодзи** в интерфейсе (сейчас есть в auth.html — убрать). Иконки — inline SVG со `stroke: currentColor`.
- Обложка проекта, если автор её не загрузил, — **однотонная заливка цветом категории**, без инициалов и фигур. Сверху бейдж категории.
- Цвет шапки профиля и фона аватара-заглушки — из палитры по хешу `user.id` (по аналогии с `resolveAuthorProjectTone`): `#C6F24E, #FF6A3D, #FFD23F, #7C8CFF, #5FD4C4, #F2B8E0`.
- Подвал на всех публичных страницах: слева `© RiseUp 2026`, справа ссылки «Проекты», «Как это работает», «Исходный код на GitHub» (`https://github.com/6yJlka/CrowdFunding`).

## Токены

```css
:root {
  --bg: #0E0E10;          /* фон страницы, фон полей ввода */
  --surface: #1C1C20;     /* карточки, панели, табы */
  --line: #2E2E34;        /* разделители, трек прогресса */
  --border: #3A3A40;      /* рамки полей и вторичных кнопок */
  --text: #F4F4F0;
  --text-2: #D6D6DC;      /* основной текст в карточках */
  --muted: #B4B4BC;
  --muted-2: #A0A0A8;     /* подписи, даты */
  --disabled: #6E6E76;

  --lime: #C6F24E;        /* главный акцент, primary-кнопки, прогресс */
  --lime-hover: #E2FF8A;
  --orange: #FF6A3D;
  --orange-text: #FF8A63; /* текст ошибок/«отклонён» на тёмном */
  --yellow: #FFD23F;
  --violet: #7C8CFF;
  --teal: #5FD4C4;
  --pink: #F2B8E0;

  --radius-pill: 999px;
  --radius-xl: 36px;      /* большие цветные блоки (шапки, hero) */
  --radius-lg: 28px;      /* карточки */
  --radius-md: 18px;      /* поля ввода, мелкие плитки */
}
```

Текст на цветных заливках (lime, orange, yellow, violet, teal, pink) — всегда `--bg` (#0E0E10).

### Статусы доната

SUCCEEDED «Оплачено» (lime), PENDING «Ожидает оплаты» (yellow), FAILED «Не прошла» (`--line` / `--orange-text`), CANCELED «Отменена» (`--line` / `--muted`).

## Компоненты

- **Шапка:** логотип (круг lime + стрелка, надпись RISEUP шрифтом Unbounded 900) · навигация-пилюля (`--surface`, активный пункт — светлая заливка) · справа действия. Навигация гостя: Проекты / Как это работает / Аналитика; «Войти» (контур) + «Запустить» (lime). В кабинетах: Проекты / Мои проекты (или Мои донаты, Модерация) + «Выйти».
- **Кнопки:** высота 44–58px, `border-radius: 999px`, `font-weight: 800`. Primary — lime/ink. Secondary — прозрачная, рамка 1.5px `--border`. На цветной шапке профиля: «Редактировать профиль» — `#0E0E10`/светлый текст с иконкой карандаша; главное действие — lime с рамкой 2px `#0E0E10`. Disabled — рамка `--line`, текст `--disabled`.
- **Табы/сегменты:** контейнер-пилюля `--surface` с padding 6px, кнопки 44px, активная — `#F4F4F0`/ink. Это `role="tablist"` + `aria-selected`.
- **Чипы категорий:** контур `--border`, активный — заливка цветом (lime в каталоге, цвет категории в форме создания).
- **Карточка проекта:** `--surface`, radius 28, сверху обложка 150–190px (картинка или цвет категории) с бейджем категории слева сверху (и «Цель достигнута» справа для FUNDED), ниже название (800), краткое описание, прогресс 8px (трек `--line`, заливка lime), строка «X ₽ из Y ₽ · N%».
- **Поля ввода:** фон `--bg`, рамка 1.5px `--border`, radius 18, высота 54. У ограниченных полей справа над полем счётчик `N / MAX`. Ошибка — рамка `--orange`, текст ошибки `--orange-text` под полем, `role="alert"`.
- **Пагинация:** «Назад · Страница X из Y · Вперёд», недоступная кнопка в disabled-стиле.
- **Пустое состояние:** карточка `--surface`, текст по центру `--muted`.

### Модалка «Редактировать профиль» (кабинеты автора и спонсора)

Аватар + «Загрузить аватар» (до 5 МБ, image/*), имя и email — **disabled** с подписью «Имя и email пока нельзя изменить» (API их не меняет), «О себе» — textarea, обязательное, до 280, счётчик. Сохранение → `PATCH /api/me/profile`. Закрытие по крестику, «Отмена», Esc и клику по подложке; фокус внутри модалки.

## Ограничения из бэкенда (не рисовать того, чего нет)

- Проект: `title` ≤ 180, `shortDescription` ≤ 300, `description` без лимита, `goalAmount` > 0, `currency` — 3 символа (по умолчанию RUB), `categoryId` необязательна, `startAt`/`endAt` необязательны; старт не в прошлом, финиш строго позже старта.
- Обложка: одна, до 5 МБ, сервер кадрирует в 16:9 (1600×900). Галереи нет.
- Редактировать поля проекта можно только в DRAFT/REJECTED.
- Донатить может только SPONSOR и только ACTIVE-проект. Анонимных донатов нет. При сумме ≥ цели проект сам становится FUNDED — значит у ACTIVE прогресс < 100%.
- CLOSED никто не выставляет; вкладка «Завершённые» фактически = FUNDED.
- Отзыв: один на пользователя, не на свой проект, оценка 1–5, текст ≤ 10 000. Комментарий ≤ 5000, есть ответы (`parentId`). Новости публикует только автор, не в DRAFT, заголовок ≤ 180, текст ≤ 10 000.
- Причина отклонения обязательна, ≤ 500. Пользователь: статусы ACTIVE / BLOCKED / DELETED, одна роль.
- Удалённый комментарий приходит как `[deleted]` — показывать «Комментарий удалён модератором» курсивом `--disabled`.

## Что сохранить

- Все вызовы API, авторизацию (`crowdfunding_auth` в localStorage), редиректы по ролям.
- i18n (ru/en): тексты новой разметки завести ключами в `i18n.js`; **селекторы в `I18N_PAGE_TRANSLATIONS` привязаны к старой разметке — их нужно переписать под новую** (лучше перейти на `data-i18n-key`).
- Доступность: настоящие `<button>`/`<a>`/`<label>`, `aria-label` у иконок-кнопок, контраст текста не ниже 4.5:1, цели нажатия ≥ 44px, вёрстка не ломается на ширине 375px.
